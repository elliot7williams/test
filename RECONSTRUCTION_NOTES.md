# NightcoreMaker.com — historical reconstruction worksheet

## Objective

Recreate the user experience of the historical nightcoremaker.com, without misrepresenting guesses as archival recovery or redistributing unknown copyrighted media/assets.

## Source status (checked 2026-11-08)

1. **Historically supported:** the site existed by at least May 2018. A contemporary user describes it as a simple MP3 upload that automatically produces a nightcore version, with minimal controls. See `ARCHIVE_RESEARCH.md`.
2. **Firsthand 2022 user memory:** a public creations feed, tracks cycling off within roughly 24h or after many uploads, an appeal to donate toward server hosting, and a possible Russian connection. This is stronger for user workflow than unverified internet assumptions, but does not establish the site's exact visual styling or wording.
3. **Unavailable:** no authenticated screenshot, original HTML, CSS, backend implementation, brand files, or archived user uploads could be retrieved by the research tools. The attempted `web.archive.org` snapshot and CDX endpoints did not yield usable content.
4. **Do not confuse** other modern websites called Nightcore Maker with this historical domain. Images of tools hosted on *nightcore.com* are not proof of the old *nightcoremaker.com* appearance.

## What v1.1 contains

- Modern default layout with uploader, audio conversion, WAV export, rights-confirmed sharing, temporary feed and donation-history note.
- **Classic view toggle:** intentionally styled as an early-web-inspired alternative using original CSS, not an exact copy. It preserves the same functional controls so users can compare layouts without losing work.
- No actual donation collection, copyrighted music library, or historical operator branding.
